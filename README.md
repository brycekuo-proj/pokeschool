# 寶可夢學堂

國小一年級 注音・國語・數學・英語 練習（依基隆市仁愛國小 115 學年一年級進度：康軒國語、康軒數學、英語字母）。
選一隻原創夥伴（草／火／水），答題拿星星讓夥伴升級、進化；每天的數學走進草叢收服怪獸，單元道館挑戰拿徽章。
